## 描述草案

观象·命盘是一座留给自己的本地观象台。

它把八字、六爻、紫微斗数和十二星座/本命星盘放在同一套可回看的流程里：先确认输入，再查看排盘事实、规则与证据，最后把现实反馈留在记录中。缺少时辰、地点或其他依据时，应用会显示范围和偏差来源，不把未知补成确定结论。

首版支持：

- 四术本地排盘与基础方向解读；
- 输入快照、引擎版本、计算时区和证据链；
- 历史记录、解释展开、事实反馈与只读复盘；
- 普通 JSON 备份和密码保护加密备份。

当前版本默认仅保存在设备本地，不接入真实短信、Apple/微信认证、云同步、AI、广告、订阅或支付。命理内容仅供传统文化研究与自我观察，不构成医疗、法律、投资或其他专业建议。
