# 观象·命盘用户协议（开发草案）

> 状态：开发草案，不是法律意见，也不是已生效的正式用户协议。版本日期：2026-09-03。

## 1. 服务范围

观象·命盘是一个本地文化工具，提供八字、六爻、紫微斗数和十二星座/本命星盘的排盘、基础解读、证据展开、保存与复盘。每个术式的输入、精度和结果范围不同，应用会显示相应的状态和边界。

## 2. 当前版本边界

首版不提供真实手机号短信、Apple/微信身份认证、云端账号、订阅、单次付费、广告、AI 解读、云端同步或推送。页面中的相关入口属于本地原型或未来接口，不构成对上述服务已上线或可用的承诺。

## 3. 输入、计算与结果

用户应尽量准确、完整地填写出生日期、时辰、地点和其他输入。应用固定记录业务时区、计算规则、引擎版本和输入快照；信息不明确时会降低结果范围或停止计算。结果依赖规则、资料和版本，不承诺预测准确、必然发生或适用于用户的现实决定；历史快照保留当时的计算元数据以便复盘。

## 4. 使用限制和风险提示

排盘或解读不得替代医疗诊断、心理治疗、法律意见、投资建议、就业决策或其他需要专业资质的判断。涉及健康、财务、安全、教育、婚姻或人身权益的决定，应咨询具备相应资质的专业人士。用户不得违法收集、传播或滥用他人的出生和身份信息，不得利用应用侵害他人隐私或合法权益。

## 5. 本地资料与备份责任

命主、记录、反馈和快照保存在当前设备。用户可以导出、导入、合并、替换或清除本机资料；导入会先预览，更高版本写入的数据会触发只读保护。用户负责设备、备份文件、加密密码和分享范围的安全，应用无法找回遗失的文件或密码。

## 6. 内容与知识产权

软件、界面、文案、算法适配和随版本提供的资料受适用法律保护。用户可在遵守法律和平台规则的前提下使用个人资料功能；不得复制、反向利用、批量抓取或重新分发受限制的数据集。地点数据只有在来源、版本、哈希、许可和署名可证明时才会进入可发布离线包。

## 7. 后续商业能力

若未来提供订阅、单次购买、广告或 AI，将分别说明价格、自动续费、退款、内容生成、数据共享、服务供应商和账号注销规则，并在上线前更新协议。本草案不构成对未来商业功能的保证。

## 8. 正式发布前必须补齐

正式协议需由运营主体和法律顾问补充：主体信息、客服与争议联系、适用法律、争议解决、未成年人规则、平台责任、服务中断、账号注销、付费退款、生效与更新机制，以及隐私政策、支持 URL 和备案信息。开发草案不应直接用于公开上线。
