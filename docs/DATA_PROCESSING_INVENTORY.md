# 观象·命盘数据处理清单

> 版本：2026-09-03。开发验收用清单；以当前代码真实边界为准，不构成法律意见。

| 数据类别 | 示例 | 当前存储/流向 | 用户控制 | 发布状态 |
| --- | --- | --- | --- | --- |
| 本地身份原型 | 本地 user id、手机号输入的原型身份、登录方式标记 | 设备本地 Storage；不上传 | 退出、清除本机数据 | 已实现；非真实认证 |
| 命主资料 | 昵称、关系、性别、出生日期/时辰 | 设备本地 Storage | 新增、编辑、删除、导出/导入 | 已实现 |
| 地点资料 | 出生地文字、确认的坐标、`locationId`、行政代码 | 设备本地 Storage；仅使用已证明的离线城市条目 | 重新选择、随命主删除 | 已实现；数据集覆盖仍受许可限制 |
| 计算快照 | 四术结果、引擎版本、计算时区、输入快照、证据链 | 设备本地 Storage | 保存、历史查看、删除、导出/导入 | 已实现 |
| 复盘反馈 | 反馈标签、备注、时间和关联记录 | 设备本地 Storage | 编辑/删除/导出/导入 | 已实现 |
| 普通备份 | JSON 文件 | 用户主动下载/分享；应用不上传 | 用户自行保存/删除/分享 | 已实现 |
| 加密备份 | scrypt + AES-256-GCM 文件 | 用户主动下载/分享；密码不上传 | 用户自行保管文件和密码 | 已实现；密码不可找回 |
| 广告/分析标识 | 无 | 不收集 | 不适用 | 当前未接入 |
| 相机/麦克风/通讯录/持续定位 | 无 | 不申请权限 | 不适用 | 当前未接入 |
| AI、支付、推送、云同步 | 无 | 不连接服务 | 不适用 | 当前未接入 |

## 风险与边界

- 出生资料和命理结果可能属于敏感的个人生活信息；首版采取本地优先、最小权限、明确备份边界，不宣称提供云端安全托管。
- 普通备份是可读文件；加密备份依赖用户密码和设备实现。文件被用户主动分享后，接收方的处理不受本应用控制。
- 未来真实登录、支付、广告、AI、统计或云同步必须重新建立数据流、供应商、权限、保留期、删除与跨境处理评估，不得沿用本清单直接上线。
- 正式运营前仍需确定法律主体、联系方式、年龄/未成年人政策、权利请求渠道、正式隐私 URL、平台标签与备案要求。
