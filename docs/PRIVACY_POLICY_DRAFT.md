# 观象·命盘隐私政策（开发草案）

> 状态：开发草案，不是法律意见，也不是已生效的公开隐私政策。版本日期：2026-09-03。

## 1. 产品与适用范围

观象·命盘面向中国大陆首发的 Web 与 iPhone，本阶段采用本地优先架构。应用提供八字、六爻、紫微斗数和十二星座/本命星盘的排盘、基础解读、证据展开、保存与复盘能力。

## 2. 当前真实处理边界

当前版本不会连接真实短信、Apple、微信、账号服务器、AI、广告、支付、推送或第三方分析服务。登录按钮是本地原型入口；命主、排盘结果、解释证据、复盘反馈和备份默认保存在当前设备，不会因使用登录入口而上传。

## 3. 数据处理清单

应用可能在设备本地保存以下内容：

- 本地身份原型标识、命主昵称、关系和备注；
- 出生日期、时辰、性别、出生地文字、已确认的坐标、`locationId` 与行政代码；
- 四术排盘结果、输入快照、计算时区/规则/引擎版本和证据链；
- 复盘反馈、收藏、历史记录和用户主动创建的普通或加密备份。

导入备份时，应用会在写入前读取并展示预览；用户确认后才执行合并或替换。

## 4. 存储、安全与备份

本地数据使用设备存储。普通备份为可读 JSON；加密备份使用本机密码保护（scrypt + AES-256-GCM）。密码不会上传，也不能由应用找回。设备系统备份、文件分享和用户自行选择的第三方文件服务可能有独立的处理规则。

应用保留历史快照的计算元数据，避免静默改写旧结果。若读取到更高 Storage Schema 版本，旧版本进入只读/不兼容状态，任何可能覆盖该 key 的写操作都会拒绝。

## 5. 用户可执行的操作

用户可以在设置中导出普通或加密备份、预览并合并/替换导入、删除单条记录、清除本机全部数据和退出本地账户原型。当前没有云端账号，因此没有云端注销、跨设备同步或在线数据访问接口。

## 6. 权限与第三方

当前原型不主动申请相机、麦克风、通讯录、持续定位或推送权限。文件选择、系统分享和设备备份由操作系统提供界面。后续接入真实登录、支付、广告、AI、统计或推送时，必须在上线前更新隐私政策、权限说明、供应商/SDK 清单和数据流，并重新经过发布审核。

## 7. 内容与风险边界

排盘结果依赖用户输入、地点确认、业务时区、历法规则、资料完整性和引擎版本。未知时辰、无法确认的地点或不完整资料会显示边界，不会猜测。命理内容仅供传统文化研究与自我观察，不构成医疗、心理、法律、投资、就业、婚姻或其他专业建议。

## 8. 正式发布前必须补齐

本草案不能替代正式法律文本。运营主体需补充并审核：主体名称和注册地址、隐私联系人及权利请求渠道、数据保留期限、未成年人/年龄分级规则、用户撤回或删除流程、第三方 SDK 与系统服务清单、跨境处理判断、备案要求、正式隐私 URL 和平台隐私标签。没有这些信息前，不得把本页当作已生效政策。
