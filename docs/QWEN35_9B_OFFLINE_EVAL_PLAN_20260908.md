# Qwen3.5-9B 离线评测方案（不接生产链路）

## 目的与边界

Qwen3.5-9B 只作为“结构化结果 → 更自然的说明”候选增强器，不参与排盘、取用、旺衰、四化或证据选择。生产用户链路保持本地规则引擎，当前不下载模型、不购买算力、不上传真实命主资料，也不把模型结果写回历史快照。

## 当前设备事实

- CPU：AMD Ryzen 5 5600，6 核。
- GPU：NVIDIA GeForce RTX 4060，8,188 MiB 显存，驱动 616.64。
- 当前仓库未安装 Qwen 模型、推理服务或模型权重；因此本报告不声称已经完成实测。

## 可实施实验

1. 准备脱敏、人工审核的 30 条结构化 fixture，覆盖八字强/弱/冲突/待定、六爻动/静/手工、紫微四化有/无、占星精确/日级近似。
2. 只向本地模型提供 `ChartPayload + ExplanationSnapshot + approved glossary`，禁止提供姓名、手机号、完整出生地点或原始备份。
3. 以 4-bit 量化为第一试验配置，记录模型版本、量化配置、上下文长度、峰值显存、延迟和失败样例。16-bit 方案只作为资源对照，不作为首发假设。
4. 约束模型输出为 JSON：`summary`、`plainLanguage`、`uncertainty`、`sourceBlockIds`。校验失败时丢弃模型输出，回退到规则解释原文。
5. 双人/双轮人工审核：不得新增原始证据中不存在的事实、不得提高置信度、不得输出应期或确定性吉凶、不得把未知时辰补成已知。
6. 以规则解释为基准计算事实覆盖率、证据引用准确率、边界遵守率和拒答/回退率；任何一项为 0 或出现隐私泄露即阻塞。

## 接入前门禁

- 模型服务必须离线或在用户设备上运行；不允许将真实档案发送到第三方 API。
- 评测产物只能是脱敏 fixture、指标和人工审核记录。
- 模型不得改变 `engineVersion`、`calculationSettings`、`inputSnapshot`、`inputFingerprint`、证据图或历史快照。
- 未通过评测和隐私/合规审核前，不在生产 UI 暴露“AI 解读”按钮。

## 当前结论

方案可实施，但本轮只完成合同与试验设计。由于模型权重尚未安装、没有独立评测集与人工审核记录，当前状态为 `blocked: evaluation-not-run`，不是“已接入”或“已实测”。
