# 观象离线城市数据说明

当前版本使用 `china-cities-p1f-mainland-v1`。它是首发中国大陆范围的离线城市表，覆盖直辖市、省会/自治区首府以及少量原型已经使用的常见地级市。坐标是城市中心近似值，业务时区固定为 `Asia/Shanghai`，不能解释为街道或区县级地理定位。

数据由观象项目人工整理和编排，当前没有复制第三方数据库文件；因此代码中的来源与许可字段明确写为“观象自有编排、上线前逐项复核”。正式发布前必须逐条复核经纬度、别名、行政区归属及可能引用的公开数据许可，并在升级数据集时递增 `datasetVersion`。历史命盘保存的 `locationId`、经纬度和数据版本不得被新版本静默替换。

城市输入只接受名称或别名的精确匹配（允许空格、逗号和句号等轻量分隔符），未知城市返回未命中，不会按包含关系、相邻城市或省份名称猜测。这样即使地点数据不完整，也不会把近似坐标伪装成精确地点。
