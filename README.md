# 观象·命盘

面向中国大陆年轻用户的本地命盘与复盘工具。首版覆盖八字、六爻、紫微斗数和西方本命盘；基础排盘与规则型解读永久免费，不接入 AI、不展示广告。

## 当前里程碑

已实现：

- Expo SDK 57 + React Native Web 跨端骨架，可复用到 Web 与 iPhone。
- 手机验证码、Apple、微信三种登录入口的原型适配层。
- 响应式登录页与“观象仪”首页。
- 八字、六爻、紫微斗数、十二星座四个模块入口。
- 四个模块各自的工作台、盘面视觉和结果进入动画，并支持系统“减少动态效果”。
- 八字四柱、六爻纳甲、紫微十二宫与西方本命盘的本地确定性计算。
- 规则型基础观察、输入不完整提示、引擎版本与解读版本记录。
- 多命主创建、选择和本地持久化。
- 命主编辑、删除及关联记录清理；记录支持单条删除与全部清空，并提供二次确认。
- 记录支持收藏筛选，以及按日记录“已发生/部分符合/尚未验证/相反”的事实反馈，方便回头复盘。
- 设置页支持带版本的本机 JSON 备份导出与导入，并在恢复前要求二次确认。
- 性别、历法、农历闰月、未知时辰与城市坐标匹配边界。
- 排盘结果自动归档，并可在记录页展开复查。
- 375px、手机横屏和 1440px 桌面布局验证。

尚未实现：

- 真实短信、Apple 与微信服务端认证。当前登录仅用于本地原型流程验证。
- 真太阳时、子初换日流派开关、完整城市坐标库与更大规模金标准回归样例。
- 加密备份已支持用户自选密码；设备迁移冲突策略和真机文件流转验收仍待补齐。
- 支付、订阅、广告和 AI 解读。

## 本地运行

要求：Node.js 22.13 或更高版本。

```bash
npm install
npm run web
```

常用检查：

```bash
npm run typecheck
npm run lint
npm test
npm run build:web
```

Web 生产构建输出到 `dist/`。iPhone 本地编译需要 macOS/Xcode；在 Windows 上可继续使用 Expo Web，后续通过 EAS 构建 TestFlight 包。

安装依赖时会运行 `scripts/patch-iztro.cjs`：它修复两个已审计开源依赖在 Expo/浏览器中的模块兼容问题，并为六爻随机种子提供跨端一致的纯 JavaScript 哈希。排盘规则代码与许可证保持不变。

## 数据边界

- 账户原型、命主、选择状态与排盘记录通过 AsyncStorage 保存在本机。
- AsyncStorage 是持久化但未加密的键值存储；正式版上线前要完成敏感字段分层与备份加密。
- 设置页提供普通 JSON 与密码保护的加密备份导出/导入；普通文件可读，加密文件使用 scrypt + AES-256-GCM。密码不会上传或找回，导入会替换当前本机资料。
- 首版账户服务只应保存身份和未来权益，不默认上传出生资料或命盘。
- 每份正式命盘必须记录输入、时区、历法、计算引擎版本和解读版本，确保可以复现。

## 设计系统

原创视觉规范位于 `design-system/guanxiang/MASTER.md`。核心母题是“观象仪”，主色为曜石黑、深玉与旧铜金。界面不得复制参考视频或第三方开源应用的品牌、布局、文案和素材。
